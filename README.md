# Smart Water Purifier System

[![YouTube Shorts](https://img.shields.io/badge/YouTube-Shorts-FF0000?style=flat-square&logo=youtube&logoColor=white)](https://youtube.com/shorts/Z50hYHpfNMk?si=Zm4ChynOQBzc7cpG)

Arduino 기반 스마트 정수기 제작 프로젝트
</br>
온수 화상 위험, 필터 수명 확인, 물 부족 감지처럼 정수기 사용 중 생길 수 있는 불편을 센서와 소프트웨어 제어로 해결하는 것이 목표

## 주요 기능

- 택트 스위치와 IR 리모컨으로 온수, 정수, 냉수 모드 선택
- 리모컨 `+`, `-` 버튼으로 온수 온도 조절
- LCD에 현재 모드와 필터 수명 표시
- RGB LED로 선택된 물의 상태 표시
- 조도 센서가 컵 접근을 감지하면 부저 알림 후 서보모터로 밸브 개방
- 출수 중 74HC595 시프트 레지스터로 8개 LED 순차 점등
- 수분 수위 센서가 물 부족 상태를 감지하면 밸브를 닫고 필터 수명 감소
- 필터 수명 상태에 따라 `Change`, `Danger` 경고 표시

## 사용 부품

| 구분 | 부품 |
| --- | --- |
| 제어 | Arduino, Arduino IDE |
| 입력 | 택트 스위치 3개, IR 리모컨/수신기, 조도 센서, 수분 수위 센서 |
| 출력 | 1602 I2C LCD, RGB LED, 피에조 부저, 8개 LED |
| 구동 | 서보모터 |
| 확장 | 74HC595 시프트 레지스터 |

## 핀 구성

| 부품 | 핀 |
| --- | --- |
| 조도 센서 | `A1` |
| 수분 수위 센서 | `A2` |
| 서보모터 | `D2` |
| RGB LED | `R: D10`, `G: D3`, `B: D11` |
| 74HC595 | `Latch: D4`, `Data: D5`, `Clock: D6` |
| 택트 스위치 | `온수: D8`, `정수: D7`, `냉수: D12` |
| IR 수신기 | `D9` |
| 피에조 부저 | `D13` |

## 코드 흐름

1. `setup()`에서 서보모터, IR 수신기, LCD, 부저, LED, 스위치 핀 초기화
2. `loop()`에서 LCD에 필터 수명 지속 표시
3. 택트 스위치 또는 IR 리모컨 입력에 따라 온수, 정수, 냉수 모드 변경
4. 조도 센서가 컵 접근을 감지하면 부저 알림 후 서보모터로 밸브 개방
5. 출수 중 LED 애니메이션 동작, 수분 수위 센서 값이 기준 이하가 되면 밸브 폐쇄
6. 출수 종료 후 필터 수명 감소, 필요 시 LCD에 경고 문구 표시

## 구현 중 해결한 문제

- `IRremote`, `LiquidCrystal_I2C` 라이브러리 버전 호환성 조정으로 LCD와 리모컨 동작 안정화
- 브레드보드 전원 레일이 중간에서 분리된 구조 확인 후 전원 라인 재연결
- 서보모터 동작 이후 IR 수신이 멈추는 문제를 `irrecv.enableIRIn()` 재호출로 해결

## 개선 방향

- `delay()` 중심 흐름을 `millis()` 기반 상태 머신으로 변경해 입력 반응성 개선
- 컵 제거 감지와 출수 중단 조건을 더 세밀하게 분리해 안전성 개선
- 음성 안내, 자동 시작 시퀀스, 실제 밸브 기구부 추가로 실사용성 개선
